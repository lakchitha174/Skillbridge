# SkillBridge — Frontend Phase 1

This is a standalone frontend prototype using only HTML, CSS, and JavaScript. It contains the login, registration, and student dashboard experience.

## Run it

1. Open `index.html` in a modern browser.
2. Select **Create an account**, register with any valid email and a six-character password, and you will be taken to the dashboard.
3. Refreshing the dashboard keeps your signed-in session. Use **Log out** in the bottom of the sidebar to end it.

All account and session data stays only in that browser's `localStorage`; there is no server or database. To fully reset the demo, clear the site's local storage in the browser developer tools.

The dashboard starts with intentionally varied readiness scores (Interview Readiness is below 40%) to demonstrate the AI practice alert.
